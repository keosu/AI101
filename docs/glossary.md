# 术语小词典

> 忘了某个词是什么意思?来这里查。词条按大致出场顺序排列。

| 术语 | 一句话解释 |
|---|---|
| **人工智能(AI)** | 让机器去做通常需要人类智能的事情 |
| **算法** | 解决问题的、清晰的、一步一步的办法 |
| **机器学习** | 让机器从数据中自己学习规律,而不是由人写规则 |
| **深度学习** | 使用多层神经网络的机器学习 |
| **模型** | 带有可调参数的"经验公式",用来做预测或生成 |
| **参数** | 模型里可调节的"旋钮",训练就是在调它们 |
| **训练** | 通过预测—算损失—调参数的反复过程让模型变好 |
| **推理** | 训练完成后,用模型对新数据做预测或生成 |
| **损失** | 预测和真实答案之间的差距,越小越好 |
| **梯度下降** | 朝着让损失下降最快的方向,一小步一小步调整参数的办法 |
| **监督学习** | 数据带标准答案的学习方式 |
| **无监督学习** | 数据没有标准答案,让机器自己发现结构 |
| **自监督学习** | 从数据自身构造"题目和答案"(如遮住词让模型猜),不需要人工标注 |
| **强化学习** | 通过尝试和奖励学会做决策 |
| **过拟合** | 死记硬背训练数据,换了新数据就表现很差 |
| **训练集/测试集** | 训练集用来学习,测试集用来检验是否真学会 |
| **神经网络** | 由很多"神经元"分层连接而成的模型 |
| **反向传播** | 从输出端逐层往回传递"误差责任",以便调整参数的办法 |
| **卷积神经网络(CNN)** | 用"小放大镜"扫描图像,擅长处理图像的神经网络 |
| **频谱图** | 把声音按时间和频率画成的"图片" |
| **词向量** | 用一串数字表示一个词,相近的词位置相近 |
| **语言模型** | 预测下一个词、判断话是否通顺的模型 |
| **RNN / LSTM** | 能逐词读文字并带有"记忆"的神经网络 |
| **注意力机制** | 让模型在处理某个词时,自动关注句子里最相关的部分 |
| **Transformer** | 只依靠注意力搭建的网络结构,是今天大模型的基础 |
| **token(词元)** | 模型处理文字的最小单位,可能是字、词或词的一部分 |
| **上下文窗口** | 模型一次能同时"看到"的内容长度上限 |
| **预训练** | 用海量数据先让模型学到通用知识 |
| **微调** | 用少量专门数据让预训练模型适应具体任务 |
| **大模型** | 参数、数据、算力规模都极大的深度学习模型 |
| **规模定律** | 规模增大时,模型性能会按规律持续提升 |
| **涌现** | 模型规模到一定程度时,突然出现的新能力 |
| **RLHF** | 人类反馈强化学习:让人给回答排名,再让模型朝更受人喜欢的方向改进 |
| **思维链** | 让模型把推理过程一步步写出来,提高准确率 |
| **幻觉** | 模型生成了听起来合理但实际是错误或编造的内容 |
| **检索增强(RAG)** | 回答前先检索资料,让模型依据资料作答 |
| **多模态** | 同时处理文字、图像、声音等多种信息 |
| **扩散模型** | 通过"从噪声中一步步去噪"来生成图像的模型 |
| **AI 智能体(Agent)** | 以大模型为大脑,能规划并调用工具完成任务的 AI |
| **图灵测试** | 判断机器是否"表现得像人"的对话测试 |
| **弱 AI / 强 AI** | 弱 AI 只擅长特定任务;强 AI(通用人工智能)指像人一样通用的智能,目前尚未实现 |
| **偏置** | 神经元里"天生想不想激活"的偏好,和权重一样是可训练的旋钮 |
| **感知机** | 最早的人工神经元模型,只能画一条直线分类 |
| **激活函数 / ReLU** | 神经元算完总分后做的"弯折"变换;ReLU 的规则是负数变 0、正数不变 |
| **前向传播** | 数据从输入层流向输出层、得到预测的过程 |
| **epoch / batch** | epoch 指把全部训练数据看完一遍;batch 指每次实际处理的一小批数据 |
| **学习率** | 每次调整参数时迈出的步子大小 |
| **随机梯度下降** | 每次只用一小批数据估计下坡方向并迈一步的训练办法 |
| **卷积核** | CNN 里的"小放大镜",在图上滑动找某种局部图案 |
| **池化** | 把相邻几个像素合并成一个,缩小图像并保留重点 |
| **目标检测** | 不仅认出物体,还要指出它在图中的位置 |
| **对抗样本** | 人眼几乎看不出差别、却能让模型出错的微小扰动图片 |
| **采样** | 把连续的声音波形按固定间隔测量成一串数字 |
| **n-gram** | 只看前面 n−1 个词来预测下一个词的统计语言模型 |
| **seq2seq** | 编码器读完一句话再由解码器写出另一句话的翻译架构 |
| **温度** | 控制生成时随机程度的参数:低则保守,高则发散 |
| **智能体(强化学习中)** | 在环境里行动、靠奖励学习的主体 |
| **探索与利用** | 尝试新选择,还是继续用已知最好的选择 |
| **Q 学习** | 给"状态—动作"打价值分的强化学习方法 |
| **协同过滤** | 找和你口味相似的人,推荐他们喜欢的东西 |
| **嵌入(embedding)** | 把词、用户、商品、图片等变成向量,放进同一空间,距离近就代表相似 |
| **冷启动** | 新用户或新内容没有历史数据时,系统难以推荐的问题 |
| **信息茧房** | 只看到自己喜欢或认同的内容,视野越来越窄 |
| **万能近似定理** | 神经元足够多时,神经网络理论上能逼近几乎任何函数 |
| **自注意力** | 句子里每个词都与所有其他词计算关注度并更新自己 |
| **基础模型** | 在海量数据上预训练、可适配许多任务的大模型 |
| **AlphaFold** | 预测蛋白质三维结构的 AI 系统 |
