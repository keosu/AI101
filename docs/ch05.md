# 第 5 章 让机器会看——计算机视觉

> **本章你会弄明白:**
> 电脑眼里的图片是什么样?为什么"认出一只猫"曾经那么难?神经网络和卷积是怎么让机器"看懂"图像的?

---

## 5.1 机器的眼睛里,没有猫

你把一张猫的照片给人看,人一眼就知道是猫。把它交给电脑呢?

电脑看到的不是"猫",而是**一大片数字**。

一张黑白照片,可以看成一张方格纸,每个小方格叫一个**像素**,每个像素用一个 0 到 255 的数字表示亮度:0 是纯黑,255 是纯白,中间是不同深浅的灰。

比如一张 28×28 像素的手写数字图片,就是 784 个数字:

```
0   0   0  12 180 255 200  30   0 ...
0   0  40 220 255 255 255 150   0 ...
0   0 100 255 120  60 200 255   0 ...
...
```

彩色图片稍微复杂一点:每个像素有三个数字,分别表示红、绿、蓝的强度。

所以,**"让机器看懂图片"的本质问题是:如何从一大堆数字里,找出"这是一只猫"这个结论?**

## 5.2 第一代办法:人来教机器"该看什么"

早期的研究者们很自然地想:那就让人来告诉电脑该看什么吧。

比如要认出人脸,他们设计了一些"特征":

- 找图像中**亮度变化剧烈的地方**(也就是边缘、轮廓)。
- 找**角点**(两条边的交叉点)。
- 统计图像里边缘朝向的分布。

然后再把这些人工设计的特征,交给一个分类器(比如我们前面讲的"画分界线")去判断。这个时代的名字很直白,叫做"**手工特征**"时代。

这种办法在一些场景里(比如检测正面人脸)确实有效,但很快遇到了天花板:

- 猫的姿势千变万化,一个侧着头、蜷成一团的猫,和一只站立的猫,边缘完全不同。
- 光线、角度、遮挡、背景……每增加一种变化,就需要工程师增加新的特征。
- **工程师设计特征的速度,永远追不上世界的复杂程度。**

这时候,一个很自然的问题出现了:**能不能让机器自己学着发现该看什么特征?**

## 5.3 请出我们的主角:神经网络

上一章里,我们认识了神经网络:神经元"加权投票",叠成多层之后能画出复杂的边界,再用"反向传播"追查责任、一点点训练。现在的问题是:**把它用在图片上,行不行?**

直接用,有个大麻烦。一张 1000×1000 的图片有 **100 万个像素**。如果每个像素都跟第一层的每个神经元相连,光是第一层就需要上百亿个连接——又慢又占内存,还极容易死记硬背。

更要命的是:**猫出现在图片的左上角还是右下角,它依然是猫。** 普通网络却把"左上角的眼睛"和"右下角的眼睛"当成完全无关的两件事,每一个位置都得重新学一遍。

所以人们需要一种**专门为图像设计**的网络结构。它的灵感来自一个生物学发现:

> 20 世纪 50~60 年代,神经科学家休贝尔和维泽尔研究猫的视觉皮层时发现:视觉皮层里的神经元,**每个只对视野里一小块区域敏感**,有的专门对某个方向的线条兴奋,有的对运动方向兴奋。大脑看东西,是**先看局部的小特征,再一层层组合成整体**。

这个发现,启发了下面这种网络。

## 5.4 卷积神经网络(CNN):用"小放大镜"扫图

**卷积神经网络(CNN)**就是这样一种为图像量身定做的网络。它的核心思想特别生活化:

> 想象你拿着一个**小放大镜**(比如 3×3 像素大小),在整张图上从左到右、从上到下,一格一格地滑过。每到一个位置,放大镜检查一下:"这块小区域里,有没有我要找的某个小图案?"

这个"小放大镜",就叫做**卷积核**(或者滤波器)。每个卷积核专门找一种图案:

- 有的负责找**竖直的边缘**。
- 有的负责找**水平的边缘**。
- 有的负责找**某种颜色的变化**。

神奇的是,这些放大镜**不是工程师设计的,而是机器自己通过训练学出来的!**

### 一层一层,从简单到复杂

CNN 有很多层,每一层的"放大镜"所看到的东西,是上一层输出的"线索图":

| 层数 | 它在找什么 | 类比 |
|---|---|---|
| 第 1 层 | 边缘、线条、颜色块 | 看到"笔画" |
| 第 2~3 层 | 角、弧线、纹理(毛茸茸、条纹) | 看到"偏旁部首" |
| 中间层 | 眼睛、耳朵、鼻子、轮子 | 看到"部件" |
| 高层 | 猫脸、整只狗、整辆车 | 看到"完整的物体" |

就像你读书:先认笔画,再认偏旁,再认字,再认词,最后读懂句子。**机器的视觉也是一层层"积木式"搭起来的。**

### 一个小细节:池化

CNN 中还经常有一种叫**池化**的操作:把相邻几个像素合并成一个(比如只保留其中最大的值)。这样图像逐渐"缩小",但重要的线索还在,计算量降低,并且让模型对物体位置的微小偏移不再那么敏感。就像你远远看一幅画,细节模糊了,但大的轮廓还看得清。

## 5.5 迭代的故事:从手写数字到几千种物体

### 第一幕:手写数字(1990 年代)

研究者 Yann LeCun 等人设计了一个早期的 CNN,叫 **LeNet**,用来识别支票和信封上的手写数字。数据集叫 **MNIST**:6 万张手写数字图片,0 到 9。这个任务如今几乎成了深度学习的"Hello World"(入门第一课)。

但那个时候,电脑算力不足,数据又少,CNN 只能在数字这种简单任务上发光发热,没引起太多人注意。

### 第二幕:ImageNet 和一次"地震"(2012 年)

斯坦福大学的李飞飞教授团队做了一件很了不起的事:收集并标注了**上千万张**图片,涵盖上千种类别,建成了 **ImageNet** 数据集。每年还办一场比赛:谁的程序在这些图片上识别得最准,谁赢。

前几年,冠军们用的都是"手工特征 + 分类器",每年的成绩提升很慢,大概只有一点点。

2012 年,一个叫 **AlexNet** 的卷积神经网络参赛。它用显卡(GPU)训练,有 8 层,几千万个参数。结果成绩比第二名好得惊人,错误率大幅度降低。整个计算机视觉领域一下子被震住了:**原来让机器自己学特征,比人设计特征好这么多!**

从那一年起,几乎所有研究者都转向了深度学习。

### 第三幕:越来越深,越来越准(2014—2015 年)

之后几年,大家不断把网络做得更深:

- **VGG**、**GoogLeNet** 等网络,把层数增加到十几、二十几层。
- 但研究者发现,**网络越深,反而越难训练**:层数太多时,"反向追责"传到前面几层时,信号几乎消失了(想想一个传话游戏,传得人越多,信息越失真)。
- 2015 年,**ResNet(残差网络)** 想出了一个巧妙的办法:**加一条"捷径"**,让信息可以跳过某几层直接往后传。就像在传话游戏里,同时还有人把原话直接递给后面的人。这样网络可以做到上百层,而依然训练得好。

此后,机器在 ImageNet 这类图像分类任务上的成绩,已经达到甚至超过普通人的水平。

> 这个故事里有个规律,你会在整本书里反复看到:
> **遇到瓶颈 → 有人想出一个巧妙的结构改进 → 瓶颈被突破 → 新的更大的难题出现。**

## 5.6 动手:在浏览器里训练一个手写数字识别器

还记得第 3 章说的"垃圾进,垃圾出"吗?我们来亲自验证一下。下面这个演示,会在你的浏览器里**现场合成训练数据**(用各种电脑字体渲染数字,并随机平移、缩放、旋转、加噪点),训练一个小神经网络,然后让你在画板上手写数字,让它认。

操作步骤:

1. 点"训练模型",等几秒,看进度条和准确率慢慢爬升。
2. 训练好后,在画板上写一个数字,抬笔就会识别。
3. 试着写得**大一点、居中、笔画粗一点**,再试着写得很小、很歪、偏在角落里,对比结果。
4. 想想:它为什么在某些情况下会认错?它"见过"什么,"没见过"什么?

## 5.7 数据比算法更重要:标注、增广和迁移学习

在计算机视觉里,有三个让"数据"变得更给力的实用技巧。

### 标注:谁来告诉机器"这是猫"?

监督学习需要**带标签的图片**。ImageNet 里的上千万张图片,是靠成千上万的人(很多是网络众包的工人)一张张标注出来的。想一想:这是一件多么大的工程!所以后来人们很在意怎样**减少对标注的依赖**,比如第 3 章提到的自监督学习。

### 数据增广:一张图当十张用

你把一张猫的照片**翻转、裁剪、稍微旋转、调亮一点、加点噪声**,它依然是猫,但对机器来说,这就是"新的"训练样本。这个技巧叫**数据增广**,上一节的手写数字演示里就用到了。它几乎是"免费"的,却能大幅减少过拟合。

### 迁移学习:站在前人的肩膀上

假设你想训练一个识别"校园里 10 种植物"的模型,但你只有几百张图片,从头训练肯定会过拟合。怎么办?

> **先拿一个已经在 ImageNet 上训练好的"老手"网络,它早已学会了看边缘、纹理、形状这些通用本领。然后只把它最后几层,改成适配"10 种植物",用你的几百张图片稍微"微调"一下。**

这就像一个已经练好基本功的运动员,转练新项目会快得多。这个想法叫**迁移学习**,是今天做小项目最常用的招数,也是第 10 章"预训练 + 微调"的预演。

## 5.8 不只是"这是猫":视觉的更多本事

认出"这张图是什么"只是第一步。计算机视觉今天还会做很多事:

- **目标检测**:不仅知道图里有猫,还知道猫在**哪里**,用一个框框出来。自动驾驶汽车靠它找行人、车辆、红绿灯。
- **图像分割**:把每一个像素都标记属于哪个物体。比如视频会议里的"虚拟背景",就是把人和背景分开。
- **人脸识别**:把人脸转换成一串"特征数字",再比较两串数字的相似度。手机解锁、门禁都靠它。
- **医学影像**:帮助医生在 X 光片或 CT 里发现可疑的病灶,当"第二双眼睛"。
- **图像生成**:不是"看",而是"画"。我们在第 11 章会讲。

## 5.9 机器的眼睛,也会"看走眼"

虽然 CNN 很强,但机器"看"的方式,和我们不一样,有时会犯很有意思的错误:

- **对抗样本**:在一张熊猫图片上,加一层人眼几乎看不出来的细微"噪点",机器就可能把它当成长臂猿,而且还很有把握!这说明机器可能依赖了一些我们根本没注意的"纹理"线索。
- **缺乏常识**:机器认出了"斑马"的条纹,但并不知道斑马是一种会吃草的动物。
- **数据偏差**:训练数据里某些人群很少,识别效果就会差,这在人脸识别里引发过很多争议。

所以,**机器的"看"是一种强大的模式识别,但它还不是人类那种带着常识的"理解"。**

## 本章小结

- 对机器来说,**图片就是一大片数字**。
- 早期靠人设计特征,遇到瓶颈;**神经网络**让机器自己学特征。
- **神经元**加权"投票",**多层网络**逐层提炼,**反向传播**像流水线逐层追责。
- **CNN** 用"小放大镜"扫图,由简单到复杂:边缘 → 部件 → 物体。
- 实用技巧:**数据增广**(一图变多图)和**迁移学习**(站在预训练网络肩上)。
- 迭代故事:LeNet → AlexNet(2012 年大爆发)→ 更深的网络 → ResNet 用"捷径"解决训练困难。
- 机器的视觉很强,但也会被"对抗样本"欺骗,并且缺乏常识。
